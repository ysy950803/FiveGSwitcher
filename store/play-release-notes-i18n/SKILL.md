# Google Play 版本说明多语言翻译（5G Switcher）

把用户给的一段**简体中文版本说明**，翻译成 Play 商店发版所需的四语代码块。核心目标是「地道」——尤其繁体要按当地语言习惯重新组织措辞，而不是简体逐字转繁体。本 App 是 HyperOS 通知中心里的 5G 快捷开关工具，涉及通知中心、快捷开关、移动网络、运行模式等术语；其中「移动网络」港台分家明显（港「流動網絡」、台「行動網路」），务必区分。品牌名 `5G` / `HyperOS` / `Shizuku` 等保持原样并注意中英间距。

## 输入

一段简体中文的版本说明。可能是纯文本，也可能只包了 `<zh-CN>` 标签或留了其它语言的空占位；无论哪种形式，都以其中的简体中文内容为翻译源。

## 输出格式

直接输出**一个 fenced 代码块**（不要额外长篇解释），语言顺序固定为 en-US → zh-CN → zh-HK → zh-TW，每段用同名标签包裹：

````
```
<en-US>
{英文版本说明}
</en-US>
<zh-CN>
{简体中文版本说明}
</zh-CN>
<zh-HK>
{香港繁體版本說明}
</zh-HK>
<zh-TW>
{台灣繁體版本說明}
</zh-TW>
```
````

## 翻译规则

1. **zh-CN 用用户原文**，仅按下面第 3 条补齐中英间距，不要擅自改写内容。
2. **繁体要地道，港台分家**：zh-HK 用港式措辞与用词，zh-TW 用台式措辞与用词。不是简转繁——要换词、换句式。常见分歧见下方对照表；表里没有的，按你对港/台软件文案习惯的判断来。
3. **中英混排加空格（pangu 间距，简繁都要）**：CJK 文字与相邻的拉丁字母/数字之间加一个半角空格，如 `5G 开关`、`HyperOS 系统`、`Shizuku 模式`、品牌名 `5G Switcher`。CJK 与全角标点（，。「」等）之间**不**加空格。
4. **英文尽量简短**：en-US 传达清楚即可，不必逐字对译，砍掉冗余；但不能丢失含义。
5. **保留原结构**：换行、项目符号（• / -）、emoji、版本号等原样保留，四种语言结构一致。
6. **控制长度**：Play 的「What's new」单语言上限约 500 字符，翻译后注意别超。

## zh-CN → zh-HK / zh-TW 高频用词对照

这些是简转繁最容易出错、且港台还会再分家的高频词，翻译时优先核对；本 App 与版本说明里出现频率高。

## 示例

**输入（zh-CN）：**

```
本次更新：
• 新增长按快捷开关直接进入设置的支持
• 优化在部分 HyperOS 机型上开关无响应的问题
• 修复切换 5G 后图标状态偶尔不刷新的问题
```

**输出：**

```
<en-US>
What's new:
• Long-press the tile to jump straight into settings
• Better reliability on some HyperOS devices where the tile didn't respond
• Fixed the tile icon occasionally not refreshing after toggling 5G
</en-US>
<zh-CN>
本次更新：
• 新增长按快捷开关直接进入设置的支持
• 优化在部分 HyperOS 机型上开关无响应的问题
• 修复切换 5G 后图标状态偶尔不刷新的问题
</zh-CN>
<zh-HK>
今次更新：
• 新增長按快捷開關直接進入設定的支援
• 優化部分 HyperOS 機型上開關無反應的問題
• 修復切換 5G 後圖標狀態偶爾不刷新的問題
</zh-HK>
<zh-TW>
本次更新：
• 新增長按快捷開關直接進入設定的支援
• 最佳化部分 HyperOS 機型上開關無回應的問題
• 修正切換 5G 後圖示狀態偶爾未更新的問題
```

注意示例里繁体的地道处理：「图标」港式「圖標」、台式「圖示」；「无响应」港式「無反應」、台式「無回應」；港式「今次更新 / 優化 / 修復 / 刷新」，台式「本次更新 / 最佳化 / 修正 / 更新」，都不是简体逐字转繁。
